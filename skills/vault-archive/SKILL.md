# 档案库工作流程

Wood 的档案库在 `D:\Data\Personal`。我负责 `01个人档案/`。建档与更新都按这里来。

规则不是铁的：Wood 随时可以口头改，改了以他为准，并更新本文件。

## 边界

- `01个人档案/` 完全归我，读 + 写，也是写给他看的。
- `03日记/` 是他写的，我只读，不写、不改。
- `02人生导师/` 不归我，不读、不写。
- `00系统模板/` 只读。
- 库根目录只放一份 `最近更新.md`（2026-10-06 起）——写给人生导师看的维护状态。**覆盖式，不是追加式**：一屏的「本次维护 / 上次维护（间隔）/ 本次改动 / 挂着没解决的 / 还没动的」。每次维护完更新它。除此之外根目录不放东西。

## `01个人档案/` 的布局（2026-10-05 重整）

原来的数字前缀是从 ai-context-vault-cn 的访谈模块顺序继承的，删掉「03 创业」之后就断了逻辑，数字只是在假装有顺序。Wood 说「编号意义不大，还有好多重复」，要求重整。现在：

- `索引.md` —— 入口。写了每份文件**装什么 / 不装什么**，防止再出现重复。
- `我的工作方式.md` —— 给 Wood 看的说明书（不是他的档案）。
- `维度/` —— 现状，会被更新。九份：个人宪法、职业与技能、健康与身体、医学事实、个人生活、社交关系、家庭、目标与规划、财务。
- `编年史/` —— 时间，只追加。一年一份，从 `2026.md` 起。
- `外发/` —— `精简版.md`，压缩 + 脱敏。

原则：**用目录表达种类，文件名表达内容，数字只留给真正有序列的东西（编年史按年）。** 以后新增文件也照这个来——不加数字前缀。

## 写档案的五条

1. 只写事实。不解读、不评价、不给建议。
2. 每条信息带来源：`（来源：2026-10-04 日记）`。
3. 原话照录，不改写、不润色。
4. 不确定 → `⚠️ 待核验`。不编。
5. 矛盾 → 不覆盖、不替他选，列出来问。

## 动作一：建档

**核心是深度访谈，不是填表。** 这是整件事里最容易被做砸的地方——如果只是问一圈基本事实，产出的是身份证复印件，不是档案。

- 一次只问一个问题，等回答。
- 不接受模糊回答。他说"还行"，就问"还行"背后是什么。
- 每个模块结尾必须问一组**不好意思说出口的**问题——那组才是档案值钱的地方。
- 顺序：`01-个人宪法` 先做，它是其余模块的地基。（他也是从 repository 里学到"先做 01"。）
- 一个问题可以跳过，跳过就跳过，不追问第二遍。
- 想到什么问什么，随时可以被打断；话题切换不用收尾。

题库：见 `访谈题库.md`。

产出：填充 `01`–`09` 维度档案；写 `00-索引.md`。`10-编年史` 和 `04-医学事实` 不走访谈（见下）。

## 动作二：更新档案

口令「更新档案」。他随时说。

1. 读 `01个人档案/` 现状。
2. 读 `03日记/` 里上次维护之后新增的日记。
3. 两件事：
   - **编年史**：日记的主要去处，按日期追加。
   - **维度档案（01–09）**：只有出现**持久性的事实变化**才改（体重变了、换工作、定了新日程）。日常流水账不进维度档案。
4. 汇报：读了几篇、改了哪些、哪些要他拍板。

**克制原则**：宁可少改维度档案，多写编年史。他说过日记对维度档案帮助不大。

## 特殊文件

- `维度/医学事实.md`：只存体检报告**原文数字**。不接受他口头复述的版本——他有把 5 条说成 2 条、把"1 个月复查"说成"半年"的记录。有出入以原文为准并提醒他。初始内容由他手动粘贴。`维度/健康与身体.md` 只放会变的数字和行为，体检原文一律指向这里。
- `编年史/<年>.md`：日记的归宿。一天一段，**段末标来源**——一天一段对应一份日记，逐条标会读得很累；只有某条另有出处时才单条标注。只留信号，不复述日记原文（细节在 `03日记/`，一步就能到）。格式：
  ```
  ## 2026-10-04 星期日

  - 建立日记系统，写下第一篇日记
  - 完成嵌入式中级备考摸底卷

  （来源：03日记/2026-10-04 星期日.md）
  ```

## 格式约定

- `索引.md` 顶部放「基本信息」（称呼 / 生日 / 城市 / 职业），它是入口也是封面。**外发版只写年龄段，不写完整生日。**
- 维度文件开头写 3–5 行「摘要」（还没内容时先不写）。
- 隐私级别标注（借自 ai-context-vault-cn 的分级，2026-10-05 起每份文件第一行都有）：
  `L1` 可给任何云端 AI / `L2` 私密，发前脱敏 / `L3` 高敏，只在本地用。
  已定：L1 = `维度/个人宪法`、`我的工作方式`、`外发/精简版`；L2 = `索引`、`维度/职业与技能`、`维度/健康与身体`、`维度/个人生活`、`维度/社交关系`、`维度/家庭`、`维度/目标与规划`、`编年史/<年>`；L3 = `维度/医学事实`、`维度/财务`。
- `外发/精简版.md` 是 L1 脱敏版，专门贴给别的 AI 用：只放能安全外发的内容，财务数字和医学细节一律不进去。
- 脱敏写法：`[已脱敏]`、`[当前公司]`、用范围代替精确值（`月入 [2-3万]`）。
