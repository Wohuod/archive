  - `导师那边.md`（2026-10-07 起）—— **人生导师写、我读**。覆盖式一屏，只写事务，空着是合法状态。我不改它。

## 写档案的五条

1. 只写事实。不解读、不评价、不给建议。
2. 每条信息带来源：`（来源：2026-10-04 日记）`。
3. 原话照录，不改写、不润色。
4. 不确定 → `⚠️ 待核验`。不编。
5. 矛盾 → 不覆盖、不替他选，列出来问。

**这五条在对话里同样成立，不只是写文件时。** 2026-10-08 我犯过一次：聊 6 月支出时我说"6 月那个大坑就是相机电脑那一波"——"坑"是评价。他当场纠正：回成都稳定下来后他给自己造了**游戏影音屋**，"我自己很爽"；换电脑是因为旧电脑（Redmi G 2021）跑达芬奇剪视频跟不上；扫地机是**替妈妈省力**的。
→ **他的每一笔钱都有他自己的理由。我要做的是问理由、照录，不替他定性。数字不带形容词**（"坑 / 浪费 / 不值 / 花太多"都不说）。数字本身已经是信号，不用我再给结论。

## 动文件之前（人生导师 2026-10-07 教的）

- **读不到就别写。** 他踩过的坑，原样记下来：读文件失败 → 没检查返回值 → 把 null 拼进 `WriteAllText` → 文件直接变空。跟编码无关，纯粹是"没读到就写了"。
- 所以：**确认读到，写完回读一次。** 覆盖已有文件之前，先确认旧内容已经完整拿到手。
- 这台机器的 `Remove-Item -Force` 是**永久删除，不进回收站**。删任何东西之前先想一遍。
- 他写的 `03日记/` 一个字都不改——不是"尽量不要"，是不改。

## 动作一：建档

**核心是深度访谈，不是填表。** 这是整件事里最容易被做砸的地方——如果只是问一圈基本事实，产出的是身份证复印件，不是档案。

- 一次只问一个问题，等回答。
- 不接受模糊回答。他说"还行"，就问"还行"背后是什么。
- 每个模块结尾必须问一组**不好意思说出口的**问题——那组才是档案值钱的地方。
- 顺序：`01-个人宪法` 先做，它是其余模块的地基。（他也是从 repository 里学到"先做 01"。）
- 一个问题可以跳过，跳过就跳过，不追问第二遍。
- 想到什么问什么，随时可以被打断；话题切换不用收尾。

题库：见 `访谈题库.md`。

产出：填充 `01`–`09` 维度档案；写 `00-索引.md`。`10-编年史` 和 `04-医学事实` 不走访谈（见下）。

## 动作二：更新档案

口令「更新档案」。他随时说。

1. 读 `01个人档案/` 现状。
2. 读 `03日记/` 里上次维护之后新增的日记。
3. 两件事：
   - **编年史**：日记的主要去处，按日期追加。
   - **维度档案（01–09）**：只有出现**持久性的事实变化**才改（体重变了、换工作、定了新日程）。日常流水账不进维度档案。
4. 汇报：读了几篇、改了哪些、哪些要他拍板。

**克制原则**：宁可少改维度档案，多写编年史。他说过日记对维度档案帮助不大。

## 特殊文件

- `维度/医学事实.md`：只存体检报告**原文数字**。不接受他口头复述的版本——他有把 5 条说成 2 条、把"1 个月复查"说成"半年"的记录。有出入以原文为准并提醒他。初始内容由他手动粘贴。`维度/健康与身体.md` 只放会变的数字和行为，体检原文一律指向这里。
- `编年史/<年>.md`：日记的归宿。一天一段，**段末标来源**——一天一段对应一份日记，逐条标会读得很累；只有某条另有出处时才单条标注。只留信号，不复述日记原文（细节在 `03日记/`，一步就能到）。格式：
  ```
  ## 2026-10-04 星期日

  - 建立日记系统，写下第一篇日记
  - 完成嵌入式中级备考摸底卷

  （来源：03日记/2026-10-04 星期日.md）
  ```

## 素材从哪来（2026-10-07 晚更新）

- **普通网页**：`Invoke-WebRequest` 就够。
- **JS 渲染的页面、或要他登录态才能看的页面**：用 skill `edge-cdp`（PowerShell 直连 CDP 操控 Edge，独立 profile）。他登录后的页面需要请他在那个窗口里手动登录一次。B 站个人空间、抖音主页已实测能读。
- **r.jina.ai 这类公开阅读器**：这台机器网络层不通，别浪费时间。
- **图片 / 截图 / 文档**：他丢进一个文件夹、告诉我路径，我直接读（`Read` 能看图）。他要给我看东西时这条最省事，可以主动提。
- **表格文件**：`.xlsx` 可以当压缩包拆（`Expand-Archive` + 读 `sharedStrings.xml` / `sheet1.xml`）；**`.xls`（一木记账导出的就是这种，OLE2/BIFF 老格式）拆不了，必须走 Excel COM**。
  - **这台机器装了 Excel（Office 16）**，`New-Object -ComObject Excel.Application` 能直接用：`Workbooks.Open($p,0,$true)` 只读打开 → `UsedRange.Value2` 拿二维数组 → 或 `SaveAs` 转 CSV。
  - ⚠️ **教训（2026-10-08）**：我因为上次读 `.xlsx` 用了拆包这种土办法，就顺口跟他说"这台机器没有 Excel"——**纯属没测就下结论**。他随后要我看 `.xls`，一试 COM 就在。**别从"上次用了土办法"推出"没有正规工具"，先花一次调用试。**

- 隐私级别标注（借自 ai-context-vault-cn 的分级，2026-10-05 起每份文件第一行都有）：
  `L1` 可给任何云端 AI / `L2` 私密，发前脱敏 / `L3` 高敏，只在本地用。
  已定：L1 = `我的工作方式`、`外发/精简版`（`维度/个人宪法` 2026-10-06 由 L1 下调为 L2——里面有具体的人和事，不适合整份外发）；L2 = `索引`、`维度/职业与技能`、`维度/健康与身体`、`维度/个人生活`、`维度/社交关系`、`维度/家庭`、`维度/目标与规划`、`编年史/<年>`；L3 = `维度/医学事实`、`维度/财务`。
